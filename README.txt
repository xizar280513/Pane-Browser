PANE BROWSER - DESKTOP SETUP

PaneBrowser.exe must remain in the same folder as WebView2Loader.dll.

The easiest way:

1. Extract the PaneBrowser-Desktop folder to the desired location, including the Desktop.
2. Do not move PaneBrowser.exe out of that folder.
3. Run PaneBrowser.exe from that folder.

If you want the Pane Browser icon to appear on the Desktop:

1. Right-click PaneBrowser.exe.
2. Select “Show more options” if necessary.
3. Select “Send to” > “Desktop (create shortcut).”
4. Use the shortcut created on the Desktop. The application folder will continue to store the EXE and WebView2Loader.dll side by side.

Pane Browser will also create a WebView2 data folder next to the executable with the name:

PaneBrowser.exe.WebView2

The Microsoft WebView2 Runtime is still required on Windows.
